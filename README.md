# OneCCacheCleaner

Windows-приложение на MFC/C++ для просмотра пользовательского списка
информационных баз 1С, контроля запущенных сеансов и очистки локального кэша.

## Возможности

- автоматический поиск `1cestart.exe` и ручной выбор файла;
- поиск и разбор `ibases.v8i` с поддержкой UTF-8, UTF-16 LE и Windows-1251;
- отображение имени, ID и текущего состояния каждой базы;
- обновление состояний каждые 2 секунды;
- мягкое закрытие отдельной базы или всех отмеченных баз через `WM_CLOSE`;
- запуск отмеченных баз с параметром `/ClearCache`;
- удаление каталогов кэша отмеченных баз из профиля текущего пользователя;
- строка состояния с результатом последней операции.

## Поиск 1cestart.exe

Поиск выполняется в порядке, заданном техническим заданием:

1. реестр текущего пользователя и компьютера, включая 32- и 64-разрядные
   представления, `App Paths` и ключи `SOFTWARE\1C\1Cv8`;
2. типовые пути:
   - `%ProgramFiles%\1cv8\common\1cestart.exe`;
   - `%ProgramFiles(x86)%\1cv8\common\1cestart.exe`;
3. ограниченный рекурсивный поиск внутри каталогов `1cv8`.

Если файл не найден, его можно указать кнопкой «Обзор…».

## Поиск ibases.v8i

Сначала проверяются пользовательские, локальные и общесистемные варианты
`1CEStart.cfg`:

- `<профиль>\1C\1CEStart\1CEStart.cfg`;
- `<профиль>\1C\1CEStart.cfg`;
- `<профиль>\1C\1cv8\1CEStart.cfg`.

Значения `CommonInfoBases` поддерживают переменные окружения, несколько путей,
пути к файлам/каталогам и относительные пути от каталога конфигурации.

Если подходящий файл не найден, проверяются:

- `%APPDATA%\1C\1CEStart\ibases.v8i`;
- `%APPDATA%\1C\1cv8\ibases.v8i`;
- `%LOCALAPPDATA%\1C\1CEStart\ibases.v8i`;
- `%LOCALAPPDATA%\1C\1cv8\ibases.v8i`.

## Определение запущенных баз

Через WMI опрашиваются `1cv8.exe` и `1cv8c.exe` только из текущего сеанса
Windows. Командная строка сопоставляется с данными `ibases.v8i` по:

- `/IBName`;
- файловому пути `/F`;
- паре сервер/база из `/S`;
- `/Ref`.

Это позволяет корректно распознавать базы, у которых отображаемое имя отличается
от имени публикации или пути файловой базы.

## Безопасность операций очистки

Перед «Очистить через 1С» и «Удалить кэш выбранных баз» приложение повторно
проверяет отмеченные базы. Если среди них есть запущенные, пользователь видит их
список и может согласиться на мягкое закрытие. Продолжение происходит только
после завершения найденных процессов; ожидание ограничено 30 секундами.
Принудительное завершение процессов не используется.

Физическое удаление разрешено только для ID в формате GUID и только в:

- `%APPDATA%\1C\1cv8\<ID>`;
- `%LOCALAPPDATA%\1C\1cv8\<ID>`.

Точки повторного анализа не обходятся, поэтому ссылка внутри кэша не может
увести рекурсивное удаление в другой каталог.

## Сборка

Требуется Visual Studio с компонентами Desktop development with C++ и MFC.

1. Откройте `OneCCacheCleaner.slnx`.
2. Выберите `Release | x64`.
3. Выполните Rebuild.

Командная строка:

```powershell
msbuild .\OneCCacheCleaner\OneCCacheCleaner.vcxproj /m /t:Rebuild /p:Configuration=Release /p:Platform=x64
```

Результат:

```text
x64\Release\OneCCacheCleaner.exe
```

Release x64 использует статическую MFC и статическую библиотеку времени
выполнения, поэтому отдельная установка MFC Runtime не требуется.

## Ограничения

- Для чтения командной строки или закрытия процесса с более высокими правами
  могут потребоваться соответствующие права.
- Если 1С показывает диалог сохранения или подтверждения, пользователь должен
  завершить его вручную в течение времени ожидания.
- Удаление кэша необратимо; резервная копия не создаётся.

## Иконка

В `OneCCacheCleaner/res` находятся прозрачный PNG-исходник 1024×1024 и
многоразмерный `.ico` (16–256 px). Знак является самостоятельным: фиолетовая
база данных, жёлтая дуга очистки и искра.
